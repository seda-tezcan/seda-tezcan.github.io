The central idea

Choose which region is active.

Opening one linked gate closes the other. The preserved region can become a resource the player deliberately holds for later.

The design opportunity

Explore a reversible board state: deciding which region should be active, rather than only which obstacle should be removed.

Access becomes a choice

Opening one linked gate closes the other. The useful region can change as goals and resources change.

A closed region preserves state

The proposal pauses the closed region. Preserving a prepared state can be useful instead of simply feeling like lost access.

Control needs predictable triggers

A cascade should not undo a deliberate choice. Only a player-created adjacent match toggles the pair.

The gate–unit loop

Each toggle creates one later damage opportunity on a Control Unit. Damage persists across three cycles.

StepRulePurpose
1 · ToggleA valid player-created match switches the linked pairMake state control deliberate
2 · ExposeThe Control Unit becomes vulnerable for one hitConnect switching to progress
3 · DamageAn adjacent match or special deals one permanent damageReward follow-through in a later move
4 · ProtectThe shield returns until the next togglePrevent an early bypass
FinishThe third damage stage removes the Unit; both gates retractResolve the access restriction permanently

Five roles for authored levels

The original level study uses a learning arc across five boards. Two introduce or extend Linked Gates; the companion boards explore timing, phased access and a shared power-up economy.

The first teaching board

A familiar damage goal lets the gate pair be the one new rule. Clarity and discovery matter more than a tight move budget.

Learn

Show cause and effect first.

The tutorial starts with one gate open and the other closed. A visible switch demonstrates the pair, then the Unit’s vulnerability is highlighted.

The closed region remains visible, so the player can understand that its contents are preserved. Later boards can change what preserving a region is worth.

“I choose which part of the board is active.”

Output and design judgment

The result is a specified interaction and a set of level roles, supported by board compositions. Human playtest outcomes have not been reported.

1reversible access mechanic
3permanent Unit damage stages
5authored level roles

The proposal’s main contribution is a controllable state that can change the value of access. Rarity was an exploration filter; a readable player decision was the selection criterion.

A strong follow-up would test whether players intentionally preserve a region and whether more than one switching sequence is useful. The revised artwork is presented as a composition study, rather than evidence of tested balance.

Five-level selection criteria

Keep a combination only if it creates a controllable timing conflict, access dependency, state dependency or shared-resource decision. An unusual appearance alone is not enough.

Reject interactions where the intended setup is dominated by outcome variance, or where one target is always the best choice without a meaningful cost.

Risks and checks
RiskDesign response or test
Accidental switchingPlayer-created matches only; test cascade edge cases
Unreadable paused stateVisible contents, a lock and a distinct paused treatment
Unit bypassOne damage opportunity per toggle; three permanent stages
One dominant sequenceTest asymmetric goals and different reasons to reopen each chamber
Too much onboarding at onceTeach the pair before the Unit damage loop
