## Scope

This repository contains only the curated portfolio. Original briefs, complete submissions and full presentation PDFs are omitted. Studio and product identifiers are omitted. Proposed tests are distinguished from documented results.

The mechanic proposals, authored board compositions and design reasoning are my contributions. Third-party visual elements are not claimed as original artwork. These are design studies and prototypes in development, rather than released commercial products. Threadworks began as a ChatGPT-assisted web prototype and moved to Unity / C#. Its audience and commercial potential have not been validated.
